# Cart2BOM

Cart2BOMは、通販サイトのカートを保存・共有可能な部品リストへ変換するUserScriptです。秋月電子通商、モノタロウ、ミスミに対応し、CSV、TSV、JSON、Markdownへ出力できます。対応店舗の商品は各サイトの一括入力機能からカートへ復元できます。

## 対応環境

- Chrome／Edge＋Tampermonkey
- Firefox＋Violentmonkey
- 秋月電子通商（`akizukidenshi.com`、`www.akizukidenshi.com`）
- モノタロウ（`monotaro.com`、`www.monotaro.com`）

スマートフォンは現時点では未対応です。

## 開発とビルド

Node.js 20以降を用意し、次を実行します。

```sh
npm install
npm test
npm run build
```

配布用UserScriptが`dist/cart2bom.user.js`へ生成されます。開発用ソースマップが必要な場合は`npm run build:dev`を使用してください。

## インストール

1. TampermonkeyまたはViolentmonkeyをブラウザへインストールします。
2. [GitHub上のCart2BOM UserScript](https://raw.githubusercontent.com/masa2429/cart2bom/main/dist/cart2bom.user.js)を開いてインストールします。ローカル開発版を使う場合は、`dist/cart2bom.user.js`をUserScript管理画面へ読み込むこともできます。
3. インストールを確認し、対応する通販サイトのページを再読み込みします。
4. 画面下部の「🛒 Cart2BOM」ボタンが表示されることを確認します。

GitHub版には`@updateURL`と`@downloadURL`が設定されています。今後のリリースでは`package.json`の`version`を上げてビルド・pushすると、Tampermonkey／Violentmonkeyの更新確認対象になります。更新確認の間隔と自動更新の可否はUserScriptマネージャー側の設定に従います。

## 使い方

1. 秋月電子通商の買い物カゴ、またはモノタロウのバスケットを開きます。
   ミスミでは「カート」画面を開きます。
2. 「🛒 Cart2BOM」から「現在のカートを読み取る」を選びます。
3. 商品画像、商品名、メーカー名、メーカー型番、販売単位、数量、備考を確認・編集します。
4. リスト名、説明、タグを入力して保存します。
5. 「保存済みリスト」から、再編集、カートへの復元、各形式の出力、管理操作を行います。保存済みリストは、現在開いている店舗の商品を含むものだけが表示されます。

保存済みリストには商品画像と明細から算出した合計金額を表示します。価格を取得できない商品がある場合は、合計へ含めず対象商品数を併記します。
常時表示する操作は「開く」と「バスケットへ追加」に絞り、CSV、TSV、JSON、Markdown、一括注文テキストは「出力」、名前変更、複製、削除は「その他」へまとめています。

秋月では、保存済みリストから「バスケットへ追加」を押すと、ブランケットオーダーの標準フォームで全商品をまとめて買い物かごへ追加します。Cart2BOMは注文を確定しません。

モノタロウでは、保存済みリストから「バスケットへ追加」を押すと、商品を10件ずつクイックオーダーへ送信します。11商品以上もバスケット画面とクイックオーダー画面を自動で往復して最後まで追加します。購入確定は行わないため、処理後にバスケットの商品、数量、価格、納期を確認してください。
モノタロウがクイックオーダー送信後に`/monotaroMain.py`でバスケットを表示する場合も、商品DOMを確認して正常完了として扱います。

ミスミでは、カート読み取り時に商品を画面上で選択し、最新の単価と出荷日が表示されるまで待ってから保存します。保存済みリストの「バスケットへ追加」では、「エクセルから一括コピー」へ型番、数量、メーカー名を渡してカートへ追加します。注文・見積の確定には進みません。
型番は商品リンクの`ProductCode`から取得し、画面上の「在庫品」などの状態表示を含めません。0.4.0で保存したリストについても、自動追加時に末尾の「在庫品」を除去します。

JSONインポートは、Cart2BOMが出力したJSONファイルまたはJSONテキストに対応します。不正データと未知のスキーマバージョンは保存前に拒否します。

## 保存とプライバシー

- リストと設定はUserScriptマネージャーの`GM.getValue`／`GM.setValue`を通じてブラウザ内へ保存します。
- UserScriptの更新確認を除き、Cart2BOM自身は商品情報を外部サーバーへ送信しません。
- 商品画像は商品ページと同じホスト、またはモノタロウの公式画像ホストにあるHTTPS画像だけを、リファラーを送信せず表示します。
- ユーザー名、パスワード、Cookie、セッショントークン、支払い情報を取得しません。
- 注文確定ボタンを操作しません。秋月とモノタロウでは、利用者が自動追加ボタンを押した場合に限り、「買い物かご／バスケットに入れる」相当の処理を行います。
- モノタロウの自動追加内容と進行状態は、明示操作後にブラウザ内へ一時保存し、完了時または有効期限切れの確認時に削除します。
- クリップボードへの書き込みとファイル保存は、対応するボタンを押した場合だけ行います。

## 免責事項

Cart2BOMが表示する情報は、読み取り時点のページ内容に基づきます。注文前に、通販サイト上の品番、数量、価格、納期を必ず確認してください。

## 既知の制限

- Chrome＋Tampermonkeyへ実インストールし、秋月電子通商のログイン済み実カート（商品12種類、数量合計53）で、読み取り、編集画面、保存、再表示を確認済みです。
- モノタロウのログイン済み実バスケット（商品3種類）でDOM構造と抽出項目を確認し、匿名化fixtureで自動テストしています。
- Edge＋TampermonkeyとFirefox＋Violentmonkey、および実ブラウザでのファイル出力、JSON再インポート、一括注文画面への貼り付けは未確認です。
- サイトの画面構成が変わると商品を抽出できない場合があります。
- ミスミはログイン済みのカートと「見積・注文」画面で利用します。選定仕様を含む最終確定型番を保存するため、同一シリーズでも型番が異なる商品は別明細になります。
