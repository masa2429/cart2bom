# Cart2BOM 手動テスト手順

実施日、ブラウザとバージョン、UserScriptマネージャーとバージョン、ログイン状態、結果、確認者を記録する。

## 事前準備

1. `npm install`、`npm test`、`npm run build`が成功することを確認する。
2. `dist/cart2bom.user.js`を対象のUserScriptマネージャーへインストールする。
3. ブラウザの開発者ツールを開き、`[Cart2BOM]`のエラーがないことを確認する。

## 対象環境

- Chrome＋Tampermonkey
- Edge＋Tampermonkey
- Firefox＋Violentmonkey
- 秋月へログインしている状態／ログインしていない状態

## 確認項目

- 秋月ドメインで固定ボタンが表示され、設定により左右へ移動する。
- カート以外で読み取りを実行すると案内が表示される。
- 空のカートで「カート内に商品がありません」と表示される。
- 1商品、複数商品、10商品以上を読み取れる。
- 数量1以外の商品を正しく読み取り、価格を数量として扱わない。
- 同じ商品への画像リンクと商品名リンクがあっても二重計上しない。
- 商品名の記号と改行が編集表および出力へ安全に反映される。
- 任意項目が欠けても、必須項目がそろう商品は表示される。
- 数量0、小数、空の商品名を保存できない。
- 保存、再表示、編集、複製、名前変更、削除が動作する。
- 同名保存と同名インポートで上書き確認が表示される。
- CSV、TSV、JSON、Markdownを保存できる。
- JSONを再インポートして内容を保持できる。
- 秋月一括注文形式で同一通販コードの数量が合算される。
- コピー操作前にクリップボードが変更されない。
- 一括注文ページを開いた後、コピー内容を貼り付けられる。
- Esc、背景クリック、閉じるボタンでモーダルを閉じられる。
- 商品数が多いとき表部分だけをスクロールできる。
- ダークモードでも固定ボタンを識別できる。
- 注文確定、外部への商品情報送信、認証情報取得が行われない。

## 実サイトDOM確認時の記録

抽出できない場合は、個人情報を除外した商品行のHTMLだけをfixtureとして保存する。ページ本文全体、Cookie、氏名、住所、セッショントークンは記録しない。
